Running REVO ARTS alongside my CS degree means most days I'm switching between Illustrator and an IDE.
That back-and-forth has been one of the most useful habits I've picked up.

## Design first, then code

Every client project starts the same way regardless of medium: understand who's using this, and what
they're trying to get done. That discipline carries directly into how I structure UI components and
API boundaries.

## Constraints are a gift

Clients rarely give you a blank canvas — there's a brand system, a budget, a deadline. Treating
technical constraints the same way (a slow network, a small screen, a screen reader) tends to produce
better software than pretending constraints don't exist.
